# Schattenbund

Ein isometrisches Fantasy-Action-RPG für Windows. Der erste spielbare Abschnitt verbindet direkte Kämpfe, zwei Begleiter und einen ausbaubaren Unterschlupf. Alles läuft lokal und benötigt keine Anmeldung.

## Starten

Godot 4.3 oder neuer: `project.godot` importieren und starten.

### Steuerung

- **WASD / Pfeiltasten:** bewegen
- **Linke Maustaste:** Hieb in Richtung Mauszeiger
- **Q:** Schattenblitz
- **Leertaste:** Ausweichschritt
- **B:** zwischen Ruine und Unterschlupf wechseln
- **E:** im Unterschlupf ausruhen
- **Esc:** Pause / zurück

Die Begleiter kämpfen selbstständig. Besiegte Gegner lassen Splitter zurück. Damit lassen sich im Unterschlupf drei Räume verbessern.

## Windows-Download

Tags wie `v0.1.0` starten den Windows-Release-Workflow. Er exportiert das Spiel und erstellt `Schattenbund-Setup.exe`.

## Technik

Godot 4, GDScript, selbst gezeichnete 2D-Isometrie. Keine externen Asset-Abhängigkeiten.
